## Contexto
El router (`bin/lib/route-engine.js`) releía y parseaba los 145 `SKILL.md`/agentes
en cada dispatch. Se añade un **índice condensado derivado** (1 fichero) que el
router consume, un **reporte de coste** accionable y se **adelgazan** las 101
descripciones >200 B sin degradar el routing.

## Cambios
**Nuevos**
- `.opencode/bin/lib/catalog-digest.js` — generador/consumidor del digest (zero-dep, LF, determinista).
- `.opencode/catalog-digest.json` — artefacto derivado: 145 entradas `{name, type, path, summary, triggers, bytes, hash}`.

**Modificados**
- `.opencode/bin/lib/route-engine.js` — `loadEntries()` lee el digest (≤1 fichero) y **degrada a `listCatalog()`** si falta/stale.
- `.opencode/bin/measure-tokens.js` — nueva superficie (sin CLI contado nuevo): `--digest`, `--digest --check`, `--catalog-report`.
- `.github/workflows/ci.yml` — paso `catalog-digest --check` en los jobs Windows y Linux.
- 101 descripciones de frontmatter recortadas a ≤~150 B (1.ª frase accionable; `triggers` intactos).
- `.agents/skills/INDEX.md`, `.opencode/AGENTS_INDEX.md` regenerados; `skills-lock.json` re-pinado.
- `.opencode/manual/README.md`, `.opencode/commands/route.md` — documentación del digest y su regeneración.

## Desvíos / Incidentes
- **Recorte de descripciones**: se aplicó una condensación determinista (1.ª frase
  accionable; cut a frontera de palabra si excede 150 B) a las 101 >200 B.
  `performance-budget` y `database-reviewer` se ajustaron a mano (≤~150 B) para
  conservar los términos que las 2 rutas ambiguas del eval necesitaban → routing
  100/23 intacto.
- **caveman / pack-reference** usaban YAML folded (`description: >`); se
  normalizaron a una sola línea citada (también mejora el `summary` del digest).
- **Determinismo CRLF/LF**: `checkDigest()` normaliza `\r\n?`→`\n` en ambos lados;
  el JSON se serializa con LF y sin timestamps.
- **Superficie**: 0 skills / 0 agents / 0 commands nuevos; `counts.clis` sigue **22**
  (el generador vive en `bin/lib/`, los `.json` no se cuentan).
- **Fallback probado**: con el digest ausente, `loadEntries()` vuelve a `listCatalog()`
  (145 entradas) y sigue ruteando bien.
