# Report: C8 — `shell.env` (exportar el stack detectado a cada bash)

Implementación del candidato **C8** (rank #1) del
`docs/reports/2026-10-07_1649-backlog-ecc-lote-largo.report.md`. El agente ahora
recibe el stack detectado como variables de entorno en cada `bash`, vía el hook
`shell.env` de opencode, para usar el runner correcto sin adivinar
(`pnpm` vs `npm`, `cargo`, `vitest` vs `jest`, …).

Decisiones confirmadas por el usuario (Q1–Q6 del PRD): plugin nuevo, lib
compartida, prefijo `OPENCODE_STACK_*` omitiendo no-detectados, cache + defensivo,
opt-out `OPENCODE_STACK_ENV=0|false|off`.

## Qué se hizo

- **`.opencode/bin/lib/stack-detect.js`** (nuevo): factory `createStackDetector(baseDir)`
  con los 6 detectores (`detectType`, `detectStack`, `detectMonorepo`,
  `detectTestRunner`, `detectLinter`, `detectFormatter`) movidos **verbatim** de
  `refresh-project.js`, + branch **.NET** (`*.csproj`/`*.sln` → `C#/.NET`, `nuget`,
  tipo `dotnet-app`). Ubicado en `bin/lib/` → **no** cuenta como CLI.
- **`.opencode/plugins/stack-env.js`** (nuevo, 4º plugin local): registra
  `shell.env` y vuelca `OPENCODE_STACK_{ENV,TYPE,LANGUAGE,FRAMEWORK,RUNTIME,PACKAGE_MANAGER,MONOREPO,TEST_RUNNER,LINTER,FORMATTER}`.
  Solo hechos detectados (nunca `"?"`), marcador `=1` solo si hay detección,
  sanitizado (trim/newlines/cap 200), no-clobber, cache por `cwd` (TTL 5s),
  try/catch global (nunca lanza), opt-out `OPENCODE_STACK_ENV=0|false|off`.
  Self-test `--selftest` con fixtures offline.
- **`.opencode/bin/refresh-project.js`**: consume la lib (`require('./lib/stack-detect.js')`)
  y elimina las definiciones locales; template/diff/preservación de secciones
  manuales intactos.
- **`evals/cases/static.json`**: invariantes `E26` (ficheros) y `E27` (hook +
  prefijo).
- **`.github/workflows/ci.yml`**: step `stack-env self-test` en ambos jobs.
- **Docs/invariantes**: `manual/README.md` (plugins + set `OPENCODE_STACK_*` +
  opt-out), `manual/ARCH.md` (árbol `plugins/`), skill `pack-reference`
  (lista de plugins), `CHANGELOG.md`; `## Counts` `plugins_local` 3→4 en los
  ficheros gestionados; `skills-lock.json` re-pinneado; `catalog-digest.json`
  regenerado.

## Caveats / notas

- **`refresh-project --check` local ≠ verde**: por doble causa preexistente y
  ajena al refactor — (1) `core.autocrlf=true` (working tree CRLF vs output LF) y
  (2) drift de `Description` (`detectDescription` vs README actual; el fichero
  commiteado tenía una descripción que ya no regenera). **No es regresión de C8**:
  los detectores movidos son verbatim y el branch .NET es aditivo; en la
  regeneración de prueba las secciones `Stack`/`Tooling` quedaron idénticas.
  No se incluyó el refresh de `docs/PROJECT.md` para no meter cambios fuera de
  alcance.
- **`.agents/skills/INDEX.md`**: regenerarlo con `build-skills-index` arrastraba
  drift preexistente (descripciones/tamaños de skills de commits previos); se
  actualizó **solo** la línea de count para mantener el cambio enfocado.
- **No tocado**: `init-opencode.js` (su `detectStack` es taxonomía de filtrado,
  contrato distinto) ni `AGENTS.md` (techo de boot/E7).
