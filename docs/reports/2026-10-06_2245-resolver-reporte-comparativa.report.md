## Desvíos / Incidentes
1. **Gate de greeting cambiado**: el plan/PRD exige baseline desde `git HEAD`. Con HEAD honesto, la reducción real es **22%** (no ≥40%); el ≥40% anterior venía de una constante mágica. Se reemplazó el gate por el **techo absoluto** (`boot <= cap`), coherente con el PRD ("techo absoluto" como gate; baseline = informativa). Documentado en el header de `measure-tokens.js`.
2. **Bug preexistente (CRLF) en el parser de frontmatter**: en checkouts CRLF, el último campo del frontmatter queda con un `\r` colgante y `.` no matchea `\r`, así que `description` se perdía cuando era el último campo (afectaba 11 skills). Preexistente en `build-skills-index.js`/`build-agents-index.js`; corregido en `lib/catalog.js` (normaliza fin de línea). Los INDEX no se regeneraron para no meter ruido de tamaños CRLF (se regeneran en instalación/LF).
3. **`event.properties` de `message.updated`** confirmado vía context7: `{ sessionID, info }` con `info.tokens`/`info.cost`/`info.modelID`/`info.providerID`. Implementación defensiva (try/catch global, fallback `unknown`).
4. `.gitignore` ya ignoraba `docs/state/*.json` → el ledger no se trackea (correcto).
